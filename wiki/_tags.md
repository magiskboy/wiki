# Tags

Danh sách tag chuẩn của kho tri thức. Mỗi tri thức chọn từ 1 đến 3 tag trong danh sách này. Khi cần tag mới, hãy cân nhắc gộp vào tag sẵn có trước để tránh phân mảnh.

## Kỹ thuật

- python — ngôn ngữ và runtime Python (async, closure, GIL, object model, hệ sinh thái...)
- web — phát triển web/frontend/backend, framework, web server, giao thức và hiệu năng web (Flask, FastAPI, Django, WSGI/ASGI, HTTP/2, C10K, React, TTFT, zero-copy, tree shaking...)
- webrtc — real-time communication trong browser, signaling, SDP/JSEP, ICE/STUN/TURN, topology multi-party (mesh/SFU/MCU), media server và protocol (Kurento, ...)
- ai — trí tuệ nhân tạo, machine learning, LLM ở mọi mức từ nền tảng toán học, ứng dụng (RAG, MCP, agent, human-in-the-loop) tới phục vụ và tối ưu suy luận (KV cache, scheduling, TensorRT-LLM, LMCache, Dynamo...)
- petrophysics — phân tích well log, facies classification, permeability prediction, mô hình hóa tầng chứa dầu khí (SOM/LVQ/ANFIS/CRP cho log giếng, mixture-of-experts cho permeability...)
- infrastructure — hạ tầng và hệ thống (Kubernetes, container, lưu trữ, mạng, vận hành...)
- game — lập trình game, game loop, FPS control, state pattern game, SDL2, game programming patterns (Nystrom)

## Tư duy và phát triển cá nhân

- mindset — tư duy, ra quyết định, giải quyết vấn đề, đánh đổi, học tập, đọc sách, kiến thức nền tảng, sự nghiệp, cộng tác, mentoring
- philosophy — triết học, đạo đức, nhận thức luận, xã hội
- finance — tài chính cá nhân
